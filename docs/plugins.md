# HyperLyric 插件

插件是 HyperLyric 的可选扩展模块，以 ZIP 包形式按需安装。每个插件提供一组相对独立的歌词处理能力，主程序负责安装、配置和运行管理。

## 能力范围

插件可以为歌词处理链增加翻译、罗马音、逐字信息、文本清洗或其他内容增强能力。具体效果取决于插件实现，以及当前歌词源是否提供了可供处理的数据。

插件处理在后台进行，原始歌词会先正常显示。插件无结果、请求失败、处理超时或结果无法通过校验时，HyperLyric 会保留当前歌词，不影响基本播放和歌词显示。

## 配置与生效

插件在插件管理中安装、配置和启用。配置修改通常从下一首歌开始生效，当前歌曲不会自动重新处理。安装、卸载或更新插件代码后，需要重启系统界面（SystemUI）；普通配置修改不需要重启。

## 缓存管理

插件缓存可在插件管理页查看和清理。点击缓存列表条目进入独立详情页：可查看插件写入的可读元数据；顶栏删除图标可删除单条缓存，「清除全部」仍在列表页顶栏。无详情信息的旧缓存条目会显示占位文案。

插件设置页中携带外链的 `action` 项，会渲染为可点击链接，点击直接在浏览器中打开，不受插件启用状态影响。

## 现有插件

- **AMLL TTML 逐字歌词**：从 AMLL TTML 数据库获取高质量逐字歌词（背景人声/翻译/罗马音），支持对唱左右分侧、缓存详情查看与歌词 API 地址自定义。
- **OpenAI 歌词翻译**：通过 OpenAI 兼容接口生成歌词翻译，并支持目标语言、模型等配置。
- **Demo 歌词插件**：用于开发和测试，通常不需要安装。

如果你需要制作新的歌词处理插件，请参阅[插件开发文档](plugin-development.md)。
